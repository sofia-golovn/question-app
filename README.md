# Вебзастосунок для пошуку та підбору домашніх улюбленців

Вебдодаток для інтерактивного підбору домашніх тварин із притулків на основі анкети користувача та миттєвої фільтрації через Algolia Search.

**Посилання на розгорнутий проєкт:** [(https://questionapp-52bq.onrender.com/)](https://questionapp-52bq.onrender.com/)

---

## Основний функціонал

- **Динамічне опитування:**
  - Підтримка 4 типів запитань.
  - Умовні переходи між питаннями залежно від відповідей користувача.
  - Повна валідація обов'язкових полів та збереження стану.
- **Інтеграція з Algolia Search:**
  - Формування складних `facetFilters` та фільтрація в реальному часі.
  - Точний мапінг параметрів (вид тварини, розмір, колір, сумісність із дітьми/іншими тваринами, вакцинація).
- **Сучасний та адаптивний UI:**
  - Чистий та інтуїтивний інтерфейс на Tailwind CSS.
  - Повна адаптивність для мобільних пристроїв та десктопів.

---

## Технологічний стек

- **Frontend:** React, TypeScript, Vite
- **State Management:** Redux Toolkit
- **Search Engine:** Algolia Search API
- **Styling:** Tailwind CSS, Lucide Icons
- **Deployment:** Render

## Інструкція з локального запуску

Щоб запустити цей проєкт на своєму комп'ютері, необхідно виконати наступні кроки:

### 1. Клонування репозиторію

Зкопіюйте проєкт до себе на комп'ютер за допомогою Git:

```bash
git clone https://github.com/sofia-golovn/question-app.git
cd назва_репозиторію
```

### 2. Встановлення залежностей

У терміналі проєкту виконайте команду для завантаження всіх необхідних пакетів:

```bash
npm install
```

### 3. Налаштування змінних середовища

Створіть файл .env.local у корені проєкту та додайте ваші ключі Algolia:

```bash
VITE_ALGOLIA_APP_ID=ваш_app_id
VITE_ALGOLIA_SEARCH_KEY=ваш_search_key
VITE_ALGOLIA_INDEX_NAME=ваш_index_name
```

### 4. Запуск у режимі розробки

Запустіть локальний сервер для перегляду вебдодатка:

```bash
npm run dev
```

Після цього відкрийте у браузері посилання, яке з'явиться в терміналі.
